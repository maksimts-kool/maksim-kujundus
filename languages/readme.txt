Estonian Translation for maksim-kujundus Theme
==============================================

To enable Estonian language on your WordPress site:

1. In WordPress admin, go to Settings > General
2. Set "Site Language" to "Eesti" (Estonian)
3. Save changes

The theme will automatically use the Estonian translation.

Translated strings include:
- "Read more" → "Loe edasi"
- "Posted in" → "Postitatud kategooriasse"
- "Leave a Comment" → "Jäta kommentaar"
- And many other interface strings

Files:
- et_EE.po - Translation source file (editable)
- et_EE.mo - Compiled translation file (binary)
- maksim-kujundus.pot - Translation template

To edit translations:
1. Edit et_EE.po file with a text editor or Poedit
2. Recompile with: msgfmt -o et_EE.mo et_EE.po
